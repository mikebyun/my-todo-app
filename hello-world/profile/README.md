# 자기소개 카드 페이지

이름, 직업, 취미를 카드 한 장에 보여주는 자기소개 페이지입니다.
보라색 그라데이션 배경 위, 화면 중앙에 흰색 카드가 표시됩니다.

## 실행 방법

이 폴더의 `index.html` 파일을 브라우저로 열면 됩니다. 별도 설치는 필요 없습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 내용 전체 (아바타, 이름, 직업, 취미 목록) |
| `style.css` | 카드 레이아웃과 색상 테마 |
| `main.js` | 페이지 로드 후 실행되는 `initApp()` 함수 (현재는 비어 있음) |
| `text.txt` | 비어 있는 연습용 파일 |

## 내용 수정하기

모든 내용은 `index.html`에 직접 적혀 있습니다.

- **아바타**: `.avatar` 안의 이모지를 바꿉니다.
- **이름 / 직업**: `.name`, `.job` 요소의 글자를 바꿉니다.
- **취미**: `.hobbies` 안의 `<li>` 항목을 추가하거나 지웁니다. 각 항목은 둥근 태그 모양으로 표시되고, 개수가 많으면 자동으로 다음 줄로 넘어갑니다.

## 색상 테마 바꾸기

색상은 `style.css` 맨 위의 `:root` 변수로 관리합니다.
아래 값만 바꾸면 페이지 전체 색상이 함께 바뀝니다.

| 변수 | 기본값 | 쓰이는 곳 |
| --- | --- | --- |
| `--primary` | `#667eea` | 배경 그라데이션 시작색, 아바타 테두리, 직업 글자, 취미 태그 글자 |
| `--primary-dark` | `#764ba2` | 배경 그라데이션 끝색 |
| `--primary-light` | `#eef0fd` | 아바타 배경, 취미 태그 배경 |
| `--text` | `#2d3748` | 기본 글자색 |
| `--text-muted` | `#718096` | "취미" 제목 글자색 |

## 동작 추가하기

클릭 이벤트 같은 동작을 추가하려면 `main.js`의 `initApp()` 함수 안에 코드를 작성하세요.
이 함수는 HTML 로드가 끝나면 자동으로 실행됩니다.
